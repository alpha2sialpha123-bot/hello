# CYBER SYSTEM — Arabic cinematic prank simulation

## تجربة المشروع
1. افتح المجلد في VS Code.
2. افتح `index.html` عبر Live Server أو افتحه مباشرة في المتصفح.
3. تبدأ المؤثرات البصرية تلقائياً.
4. بعض متصفحات الهاتف تمنع الصوت التلقائي؛ المس الشاشة مرة واحدة لتفعيل المؤثرات الصوتية.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع `index.html` و`style.css` و`script.js` إلى جذر المستودع.
3. افتح Settings → Pages.
4. اختر Deploy from a branch ثم `main` والمجلد `/(root)` واضغط Save.
5. استخدم الرابط الذي يظهر في صفحة Pages بعد اكتمال النشر.

## الخصوصية
واجهة مسح الوجه رسم متحرك وليست قراءة حقيقية للوجه. لا يتم فتح الكاميرا أو قراءة الصور أو جهات الاتصال أو الملفات ولا إرسال بيانات إلى خادم. الأصوات مولدة محلياً بواسطة Web Audio API. صفحة الويب لا تستطيع إجبار المتصفح على الإغلاق أو منع إعادة فتح الرابط بشكل موثوق.


## إضافة صوت الإنذار
ضع ملف الصوت الذي تملكه باسم `alarm.mp3` في المجلد نفسه الذي يحتوي على `index.html` و`script.js`. تمت إضافة عنصر الصوت إلى الصفحة تلقائيًا. يحاول الموقع تشغيل الصوت عند ظهور الشاشة النهائية؛ قد يمنع Chrome أو Edge التشغيل التلقائي بصوت مسموع حتى يتفاعل المستخدم مع الصفحة. اضغط Escape لإيقاف الصوت.
